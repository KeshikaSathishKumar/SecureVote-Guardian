Key Features

🔒 End-to-End Privacy

Votes are always encrypted. Only final tallies are revealed — never individual choices.

🤝 Threshold Trust

Private key is split across trustees. A quorum must cooperate to decrypt results.

📋 Tamper-Evident Logs

Every operation is hashed into an immutable audit log that anyone can verify.

🔬 First-Principles Crypto

Pure Python Paillier encryption — no third-party crypto libraries required.

How It Works

1

Get Token

Voter receives an eligibility token linked to an anonymous ID.

2

Encrypt Vote

Browser encrypts your choice using Paillier homomorphic encryption.

3

Server Aggregates

Server multiplies ciphertexts — computing the sum without seeing individual votes.

4

Trustees Decrypt

Trustees jointly reconstruct the private key to reveal only the final tally.
